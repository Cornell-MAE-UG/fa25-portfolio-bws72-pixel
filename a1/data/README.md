This program uses the historical dictionaries files from wordle, data/wordle-La.txt, and data/wordle-Ta.txt.
The text files data/small-dictionary.txt and data/small-secret-dictionary.txt are used just for testing.
data/wordle-La.txt contains the words that can be selected as the secret word, and can be guessed. 
data/wordle-Ta.txt contains the words that can guessed, but cannot be selected as the secret word. 
To edit the dictionary used for the game, simply edit either of the dictionary files, wordle-La.txt and wordlw-Ta.txt, by adding or deleting words.
